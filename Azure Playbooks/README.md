# Azure Playbooks

Incident-response playbooks for Azure, starting with AKS. Each is dual-format (NLP steps for AI agents plus CLI commands using `az` and `kubectl`).

| Folder | Playbooks |
|--------|-----------|
| `01-AKS/` | `NodePoolNotScaling-AKS.md`, `ImagePullFailedFromACR-AKS.md`, `LoadBalancerNotProvisioning-AKS.md`, `ManagedIdentityAuthorizationFailed-AKS.md` |
